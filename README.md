# gittkport  
  
1.  gittkportについて
これまでに得たスキルをアウトプットするため、ポートフォリオの制作に取り組みました。  
また、github活用のため、本リポジトリを作成しました。
  
2.アプリ概要
　・家計の支出を記録するアプリ。  
　・機能は、支払情報記録と支出明細照会の２種類。  
　・照会した明細はCSV形式のファイルでダウンロードが可能。  
　※一部のユーザーのみに対しアプリURLを公開しています。

4.機能説明  

　○支払情報入力  
　　①支払情報入力画面にて各項目を入力。科目はセレクトボックスから選択。  
  　　“入力”ボタン押下でバリデーション実行。不備があると警告文が表示。問題がなければ確認画面に移行。  
　　②入力情報確認画面に移行。内容に問題がなければ”登録”ボタン押下。  
  　　入力情報がデータベースに登録され、支払情報入力に移行。”やり直す”ボタン押下で入力値を保持したまま支払情報入力に戻る。  
　○明細照会  
　　①条件指定画面で期間および科目を指定。“照会”ボタン押下後、  
  　　指定条件と登録ユーザーidを基にpay_infosテーブルからレコードを抽出し、照会画面に移行。  
　　②照会画面にて、ページングにより1ページにつき10件のレコードが表示される。  
 　　明細データを入手したい場合、”ダウンロード”ボタン押下でCSV形式のファイルをダウンロードすることが可能。  
　○月別支払状況  
　　①期間指定画面で期間を指定。“照会”ボタン押下後、支払状況画面に移行。  
　　②行：時期（YYYY-MM形式）で列：科目の表に、月別・科目別の出費合計額が表示される。
